Je n'héberge pas ce site, tu dois donc le lancer en local (sur ta machine)

Installe Node.js ==> https://nodejs.org/en

Place toi dans le dossier racine du projet (celui qui contient /public /src et surtout le package.json)

Ouvre un terminal (en mode administrateur souvent) à cet emplacement et installes les 'petites' dépendances (le nécessaire pour lancer le site en local, imiter un serveur web)
en tappant

### `npm install`

ou

### `npm i`

Une fois l'installation terminée, tu tappes

### `npm start`

Et ça fait des chocapic !

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.
